# Face-validation form for the 50 LDA themes
Per PROPOSAL_diffusion §2.4: each rater marks every theme as
`coherent` (the cluster names a recognizable business-model
component), `partial` (it captures something but is mixed/noisy),
or `noise` (no recognizable theme). A theme is promoted to the
headline set if rater agreement on `coherent` is >= 0.8.

Source: 200k stratified granted-filing sample from classes
009/042/039/035, LDA T=50, min_df=200 (V=69,361). For each
topic, eight representative marks are shown (top-topic weight
≥ 0.30, post-burn-in 1996–2020, ≥ 12 words).
