# docs/

Reference materials for the trademark project: papers, USPTO documentation, attached PDFs, anything Eric pastes in as a primary source.

Drop files here as-is. Don't rename them aggressively - keep enough of the original filename to be searchable. If a doc is huge (>5 MB) or sensitive, consider whether it belongs here or as a pointer in `../INBOX.md`.

Working notes and lit-review summaries belong in `../notes/`, not here.
